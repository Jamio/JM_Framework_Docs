# Contributing

Documentation corrections, clearer explanations, screenshots, examples, and component details are welcome.

## Principles

- Keep component-specific information on the component's page.
- Link audience guides to component pages instead of duplicating instructions.
- Clearly distinguish released behaviour from planned behaviour.
- Verify technical details against the current framework source.
- Prefer concise examples that can be tested in multiplayer.

Open an issue or pull request in the [documentation repository](https://github.com/Jamio/JM_Framework_Docs) when proposing a change.
