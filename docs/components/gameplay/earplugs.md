# EARPLUGS

## Overview

Earplugs provides simple virtual ear protection without requiring a physical inventory item. Players can insert or remove them through ACE Equipment.

## How to set up the component

Place **[JMF] - Core > Optional Systems** and enable **Earplugs** under Lightweight Systems.

## 3DEN Module Settings

### Optional Systems — Lightweight Systems

| Attribute | Default | What it does |
| --- | --- | --- |
| Enable Earplugs | Enabled | Adds the insert/remove earplug ACE self-actions. |

## ZEN Modules

Earplugs has no dedicated ZEN modules.

## Troubleshooting

- The action is under **ACE Self Interaction > Equipment**.
- If the action is absent, confirm Earplugs is enabled and the player has a working ACE interaction menu.
