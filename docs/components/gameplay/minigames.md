# Minigames and Field Procedures

Minigames provide interactive field procedures derived from Waldo's mission systems while retaining their original visual style.

Procedure definitions control the object, challenge type, attempts, access rules and success/failure handling. Supported procedures include practical interaction puzzles and keypad-style challenges.

The server owns attempts and resolution; the interactive dialog runs on the participating client. Zeus can register procedures, configure tables and administer active attempts.
