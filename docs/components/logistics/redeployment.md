# Redeployment

Redeployment combines rally points, squadmates, fixed deployment points, command vehicles and reinsertion requests in one themed map dialog.

Place Redeploy Settings and enable the destination families required by the mission. Redeployment Point modules are synchronized to world objects and can display world labels. Command Vehicle modules designate eligible vehicles.

The server validates destination identity, group relationship, enemy proximity and vehicle capacity before moving a player. Zeus can register destinations, choose the command vehicle and change available destination families during play.
