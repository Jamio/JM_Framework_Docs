# Arsenal and Roles

Arsenal supports a restricted ACE Arsenal and a role-picker dialog backed by mission loadout definitions.

Configure the source preset or `loadouts.hpp`, save policy, side-aware item pools and role definitions in Arsenal Settings. Arsenal Object modules are synchronized to the terminals or crates players use.

Role definitions can specify a display name, loadout, side availability, traits and a concurrent player limit. The server approves role selections before the client applies the loadout. Zeus can configure access objects and assign framework roles to units during play.
