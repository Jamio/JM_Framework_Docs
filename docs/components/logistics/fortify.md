# Fortify

Fortify extends ACE Fortify with framework-owned catalogues, budgets, crates and refillable resource points.

Define buildable objects and costs in `fortify.hpp`. Place Fortify Settings, then synchronize Fortify Crate or Resource Point modules to world objects. Crates expose construction actions without ACE's duplicate budget title; resource points replenish a nearby crate after an ACE progress action.

Zeus can create/remove crates and resource points and adjust budgets. Registries and actions are synchronized for JIP players.
