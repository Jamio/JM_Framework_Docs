# Briefing

The Briefing component turns structured Eden text fields into one consistently formatted Mission Briefing diary record.

Place one **Briefing Setup** module and complete only the relevant sections: Situation, Area of Operations, OPFOR, Civilians, ROE, Mission, Execution, success/failure conditions, Resupplies, Respawns, Redeployment, Communications and Miscellaneous. Empty sections are omitted.

Use separate **Briefing Entry** modules for information that should not appear inside the main record. Entries are created locally for players and refreshed when their playable unit changes.
