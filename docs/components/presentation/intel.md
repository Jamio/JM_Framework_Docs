# Intel

Intel supports two player experiences:

- **Diary Intel** is collected through an ACE interaction and added to the appropriate players' diaries.
- **Readable Intel** opens a leaflet-style image and text display without permanently recording its contents.

Place Intel Settings, then configure the relevant child module and synchronise it to the world object. Set ownership/side restrictions carefully. The default document icon is `z\ace\addons\intelitems\ui\document_ca.paa`.

Collected records and registered objects are server-owned and rebuilt for JIP clients.
