# Debriefing

Debriefing displays a themed mission-result screen before the vanilla mission ending. Configure success/failure summaries, optional imagery, display duration, automatic ending and team commendations in **Debriefing Settings**.

Synchronise an **End Mission with Debriefing** module to a trigger, or invoke the equivalent Zeus module. When activated, Player Statistics are flushed to the server before the dialog is populated.

The screen includes the mission title, result, summary, personal performance and grouped team commendations. Use an outro Cutscene Sequence when a cinematic should lead into it.
