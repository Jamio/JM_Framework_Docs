# Optional Systems

The Optional Systems module collects smaller client-facing features that do not need independent Eden categories.

## Available systems

- aid-station deployment;
- earplugs and stamina behaviour;
- screenshot mode and ACE Arsenal face/voice restrictions;
- private messages;
- nametags;
- forestry tools;
- unknown-weapon penalties;
- identities and death-camera settings.

Each subsection has its own enable toggle and attributes. Disabling a subsection prevents its player-facing handlers or actions from starting.

## Eden setup

Place at most one **[JMF] - Core > Optional Systems** module. Only enable features the mission will use. Large systems such as CBRN, Supply and Garage retain dedicated settings modules.
