# Tickets

Tickets maintain server-authoritative reinforcement pools by side. Deaths consume tickets according to the configured lifecycle rules.

Recovery Point modules turn synchronized objects into bodybag processing stations. Mission makers configure the reward per bodybag, interaction radius, display name and world label. The ticket-check action is attached to recovery objects rather than the player's self-interaction menu.

Zeus can inspect and adjust ticket pools and create or remove recovery points. Recovery actions are JIP-persistent.
