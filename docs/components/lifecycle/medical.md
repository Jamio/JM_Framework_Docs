# Medical

Medical adds an optional delayed unconscious spectator view, a compact vitals HUD and 3D markers above unconscious friendlies.

The Eden module separates spectator behaviour, HUD content and unconscious-marker settings. The HUD reads ACE medical state, including heart rate, blood pressure, blood volume, wounds, medication and the nearest medic. Some values depend on the ACE medical settings used by the mission.

The marker system supports group/side/global visibility, AI inclusion, range, fade distance and line-of-sight requirements.
