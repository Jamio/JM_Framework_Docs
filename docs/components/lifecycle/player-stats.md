# Player Statistics

Player Statistics tracks combat, survival, medical and movement performance for Debriefing.

Tracked values include kills, vehicle kills, longest kill, shots, launcher rounds, grenades, explosives, deaths, unconscious events, treatments, damage received and distance travelled. Team commendations translate leading values into readable awards such as Top Killer, Desmond Doss, Ironman and Reincarnated.

Clients batch frequent counters before sending them to the server. The server publishes periodic snapshots and Debriefing forces a final flush before displaying results.
