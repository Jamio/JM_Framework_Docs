# Identities and Death Camera

Identities assign a new character identity for each life. Names, ranks and death quotes can use framework defaults, mission additions and side-specific pools. Quote modes support Serious, Fun and Mixed selections.

The Death Camera displays the dead character and pulls upward while keeping the body as its target. It can show the identity, lifespan and a selected quote before the normal respawn flow continues.

Both systems are configured under Optional Systems. Identity reassignment occurs after respawn so each life represents a different character.
