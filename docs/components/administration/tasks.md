# Tasks

Tasks lets mission makers define structured BIS tasks in Eden and manage them through Zeus.

Place Task Settings, then one Task module per task. IDs are unique and case-sensitive. Configure owner, title, description, destination, parent, state, notification behaviour and optional success/failure conditions. Start a task as **Hidden** when it should be revealed later.

Zeus can create tasks and move existing tasks between Hidden, Created, Assigned, Succeeded, Failed and Canceled states. The server owns task state and uses the BIS task framework for synchronization.
