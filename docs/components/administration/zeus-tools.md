# Zeus Tools

Zeus Tools contains mission effects and utilities that do not belong to one gameplay component.

Available tools include HUD countdowns, random anti-air fire, instant explosions, ambient artillery, ground-launched flares, ambient effects, cutaways, cinematic borders, storms, lightning, temporary sight impairment, flyovers and unit flinging.

Persistent effects store server state so JIP clients can reconstruct them. One-shot effects are intentionally transient. Server handlers validate the assigned curator for Zeus Tools requests.
