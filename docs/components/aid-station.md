# Aid Station

## Overview

The Aid Station component provides a deployable ACE medical facility with a composition and global map marker.

!!! warning "Documentation to be verified"
    The component has an initial working implementation. Exact configuration, class names, events, and limitations will be documented against the current JM Framework development branch.

## Players

Eligible medics can deploy an aid station through ACE self-interaction. The deployed facility can be used by ACE medical systems and is identified by a map marker.
