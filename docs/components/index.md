# Component Catalogue

Component pages are the authoritative documentation for individual JM Framework features. Each page uses the same structure:

- **Overview** — what the component does and its current status
- **Players** — what players see and how they use it
- **Mission Makers** — Eden setup and configuration
- **Zeus** — ZEN controls and runtime behaviour
- **Technical reference** — dependencies, state, events, functions, and locality
- **Troubleshooting** — known problems and checks
