# Final Validation Checklist
A practical sign-off before the operation is announced as ready.
</div>

<!-- Optional header image: docs/assets/images/mm-validation-checklist.jpg -->

## Mission content

- [ ] Briefing, tasks, markers, and role information are complete.
- [ ] Objectives can be identified, completed, failed, and recovered.
- [ ] Player slots and loadouts match the expected attendance.
- [ ] Enemy forces, reinforcements, civilians, and support are reviewed.
- [ ] Win/fail/end conditions work.

## Framework systems

- [ ] Core framework initialises without relevant RPT errors.
- [ ] Every enabled component has been tested from the player perspective.
- [ ] Respawn, JIP, death, disconnect, and repeated-use behaviour are checked.
- [ ] Side- and role-restricted systems show the correct options.
- [ ] Zeus/ZEN controls are available and behave as documented.

## Server readiness

- [ ] Mission package and filename are correct.
- [ ] Server and clients use the intended mod versions.
- [ ] Dedicated-server load test passed.
- [ ] Performance is acceptable at representative AI/player counts.
- [ ] A known-good rollback copy exists.

## Operation-night readiness

- [ ] Briefing and mod preset are published.
- [ ] Zeus notes and contingencies are prepared.
- [ ] Required specialist/leadership roles are understood.
- [ ] Technical issues and limitations are communicated.
