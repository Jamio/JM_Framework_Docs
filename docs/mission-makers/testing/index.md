## Testing stages

1. **Editor review** — slots, modules, markers, attributes, dependencies, and obvious omissions.
2. **Local playtest** — objectives, loadouts, interactions, pacing, and basic scripts.
3. **Multiplayer test** — locality, respawn, JIP, permissions, and synchronisation.
4. **Dedicated server validation** — server mod set, signatures, logs, headless client, and packaging.
5. **Final rehearsal** — briefing, Zeus tools, fallbacks, and end conditions.
