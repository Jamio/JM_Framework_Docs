# Mission Maker Guide

This section is the practical route for building an Arma 3 mission with JM Framework.

## Recommended route

1. [Install and enable the framework](getting-started.md).
2. [Build your first framework mission](first-mission.md).
3. Learn how [Eden modules and attributes](eden.md) configure components.
4. Open the relevant page in the [Component Catalogue](../components/index.md).
5. Review [side-aware and TvT design](side-aware.md) when supporting more than one player side.
