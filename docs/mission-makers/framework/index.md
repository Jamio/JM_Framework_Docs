## Framework setup journey

1. Load JM Framework and its required dependencies.
2. Create or open the mission in Eden.
3. Place and configure the required core setup.
4. Add only the components the operation needs.
5. Configure each component around the mission design.
6. test the player experience and Zeus controls.
