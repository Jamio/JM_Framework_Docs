How to install, update and troubleshoot the mods required for our operations.

## Our approach to mods

We use a curated mod preset so everyone has the same content and compatible mod versions. We do not generally allow client-side mods, due to previous experiences.

**Modlists are posted alongside the mission briefings, or in the sign-up channel.**

## Installing the preset

Our preset is provided as an HTML file that can be imported directly into the Arma 3 Launcher.

1. Download the latest preset using the link on the briefing document.
2. Open the **Arma 3 Launcher**.
3. Select **Mods** from the left-hand menu.
6. Locate the downloaded HTML preset.
7. Drag and drop the HTML file over the launcher.
8. Allow Steam Workshop to subscribe to and download any missing mods.
9. Save the imported preset with a recognisable name.

Steam may need some time to download the complete modset. Keep the Launcher open until every required mod has finished downloading.

Check that the number of loaded mods at the top of the page matches the defined number in the briefing document.

## Updating before an operation

Check for mod updates before every operation—ideally earlier in the day rather than immediately before the advertised start time. Steam will normally update things automatically, but be sure to chec anyway.

!!! warning "Do not leave updates until the start time"
    Large mods can take a while to download. Do not leave them until the evening of the operation if you can avoid it.


If you have any issues with mods, post your issue in arma-chat, and someone will be able to help yuo troubleshoot.
