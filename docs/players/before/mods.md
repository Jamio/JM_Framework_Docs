## Our approach to mods

We use a curated mod preset so that everyone joins with the same content and compatible versions. This reduces technical problems and gives Mission Makers a consistent set of assets and systems to work with.

The current preset may undergo light changes. The most recent modlist will be available in the current briefing document, or the base modlist can be provided to new players.

Do not add unfamiliar mods to the preset without checking first. Even client-side mods can sometimes cause compatibility problems, prevent you from joining the server, or create technical issues that other players cannot solve.

## Installing the preset

Our preset is provided as an HTML file that can be imported directly into the Arma 3 Launcher.

1. Download the latest preset using the link on the briefing document.
2. Open the **Arma 3 Launcher**.
3. Select **Mods** from the left-hand menu.

7. Drag and drop the HTML file over the launcher.
8. Allow Steam Workshop to subscribe to and download any missing mods.
9. Save the imported preset with a recognisable name.

## Updating before an operation

Check for mod updates before every operation—ideally earlier in the day rather than immediately before the advertised start time.

Steam normally updates Workshop mods automatically, but downloads may be delayed while Arma 3 or the Launcher is running. Open Steam and the Arma 3 Launcher early enough to confirm that:

- No Workshop downloads are pending.
- No required mods are marked as missing or corrupted.
- The correct preset is selected.
- Arma launches without mod-related errors.

If the preset itself has changed, download and import the latest version announced on Discord.

!!! warning "Do not leave updates until the start time"
    Large mods can take a while to download. Allow at least **[ADD RECOMMENDED PREPARATION TIME]** before joining an operation.

## Optional and prohibited mods

### Optional client-side mods

We recommend against loading optional client-side mods. Our full modlist is catered to provide the appropriate clientside QOL fixes and adjustments.

Loading addiitonal clientside mods can sometimes mean that you will experience errors//bugs/technical issues that other players are not experiencing and therefore cannot assist with.

Optional mods are used at your own risk. If you experience crashes, unusual behaviour or difficulty joining, disable them before troubleshooting the main preset.

## Common setup problems

### A required mod or dependency is missing

Check that Steam has subscribed to every mod from the imported preset. Missing dependencies are usually shown in the Launcher beneath the affected mod.

One some occasions, however, we have opted not to use a dependency for a particular reason. If you are unsure, ask.

If required, open the mod's Workshop page, subscribe to the missing dependency and allow it to finish downloading.

### The server reports a signature mismatch

A signature error usually means that your installed version differs from the server version.

1. Close Arma 3 and the Launcher.
2. Check Steam for pending Workshop downloads.
3. Restart Steam if the update does not begin.
4. Repair the affected mod through the Launcher if necessary.
5. Rejoin once the download or repair has completed.

!!! tip "Signatures"
    We don't tend to use signatures and keys much these days, so this is unlikely to be the issue, but the steps abvove are a great first step in troubleshooting mod errors.

### A mod is corrupted or will not load

Open the mod's options in the Launcher and select **Repair**. Steam will verify and redownload any missing or damaged files.

If repairing does not work, unsubscribe from the mod, allow Steam to remove it, and then subscribe again.

### The Launcher does not import the preset

Confirm that you downloaded the HTML file itself rather than opening it as a webpage or saving it as a text file.

If the import still fails:

1. Restart the Launcher.
2. Download a fresh copy of the preset.
3. Check that the filename ends in `.html`.
4. Ask for help in the support channel.

### Arma crashes or behaves unexpectedly

First, confirm that you are using the current preset without additional mods. Disable optional mods and test again.

If the problem continues, provide the support team with:

- What you were doing when the problem occurred.
- Any error message displayed.
- A screenshot where useful.
- Your Arma 3 RPT log, if requested.
- Whether the issue also occurs with only the official preset loaded.
