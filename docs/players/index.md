# Player Guide

This section explains how to use JM Framework features during an operation. It focuses on actions and information relevant to players without requiring mission-building knowledge.

## Start here

1. Read [Getting Started](getting-started.md).
2. Learn the framework's [Common Interactions](interactions.md).
3. Use the [Component Catalogue](../components/index.md) to find the system you need.

Community-wide topics such as medical and radio procedure live in the [Community Guides](../community/index.md).
