# Component Page Template

New component guides should use the following structure and omit headings that do not apply.

```markdown
# Component Name

One-paragraph purpose and player experience.

## Enable the component

Required settings module or Core/Optional Systems toggle.

## Eden setup

Ordered setup steps, synchronization and important attributes.

## Mission definitions

File path, schema and a minimal working example.

## Player experience

Actions, dialogs, restrictions and failure feedback.

## Zeus

Available ZEN modules and whether changes persist for JIP.

## Multiplayer

Authority, locality, respawn and JIP behaviour.

## Troubleshooting

Common validator codes, mistakes and diagnostic steps.

## Public API

Only supported functions/events with exact signatures.
```

Write from implemented code, not the planning sheet. Clearly label experimental or planned behaviour.
