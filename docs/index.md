# JM Framework

The official guide to **JM Framework** and the systems used by the **Misfits Arma 3 community**.

JM Framework is a modular mission framework for building and running Arma 3 operations. This site brings player guidance, community standards, Mission Maker setup, Zeus controls, and technical reference together in one place.

!!! note "Documentation in development"
    JM Framework and this documentation are being developed together. Pages marked as planned establish the intended structure but may not yet describe a released feature.
