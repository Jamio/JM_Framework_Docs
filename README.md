# JM Framework Documentation

Source for the official [JM Framework documentation site](https://jamio.github.io/JM_Framework_Docs/).

This repository documents the framework itself: installation, Eden configuration, component behaviour, Zeus controls, public integration points, multiplayer architecture and troubleshooting. Community rules and general Arma 3 training material are intentionally out of scope.

## Local preview

```text
python -m pip install -r requirements.txt
mkdocs serve
```

The deployment workflow runs `mkdocs build --strict` and publishes the generated site through GitHub Pages.
